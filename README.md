# Orbit — Motion Interface Study

A responsive, motion-focused dashboard concept built to explore visual hierarchy, orbital animation, subtle glow effects and small interactive UI details.

This is an original interface experiment. It uses a dark visual system, a CSS-only orbital illustration, sample dashboard metrics and a filterable activity stream.

## Preview locally

No build tools or package installation are required.

1. Clone the repository.
2. Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

3. Visit `http://localhost:8000`.

## Features

- Responsive layout for desktop, tablet and mobile
- CSS orbital illustration with continuously animated paths
- Dashboard metric cards and compact data visualisations
- Interactive activity filters (All, Focus, Build)
- Glow intensity toggle
- Keyboard-friendly native links and buttons
- Reduced-motion support through `prefers-reduced-motion`
- No framework or runtime dependency

## Built with

- Semantic HTML
- CSS custom properties, grid, flexbox and keyframe animations
- Vanilla JavaScript
